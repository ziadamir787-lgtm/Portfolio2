# Ziad Amir — Personal Portfolio

A responsive bilingual (Arabic/English) static portfolio website.

## Contents
- `index.html` — page structure and metadata
- `style.css` — Cyber Tech responsive design
- `script.js` — language toggle, poem archive/search, artwork lightbox, mobile navigation
- `assets/` — six original artwork photos and PackHouse ERP project screenshot

## Run locally
Open `index.html` in a modern browser. No build step or package installation is required.

## Publish
Upload the contents of this folder (not the outer folder itself) to Netlify Drop or the static hosting provider of your choice.

## Personal photo
The hero currently contains a designed placeholder. Replace it when the final profile photo is selected.
